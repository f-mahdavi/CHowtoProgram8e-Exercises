# C How to Program, 8th Edition — Exercises

This repository contains my personal solutions to the end-of-chapter exercises from *C How to Program, 8th Edition* by Paul Deitel and Harvey Deitel.

## Purpose

The goal of this repository is to practice C programming, strengthen problem-solving skills, and reinforce the concepts covered in the book.

## Contents

Solutions are organized by chapter, with each file corresponding to an exercise.

## Disclaimer

These solutions are my own work and are intended for learning and educational purposes.
